# Проект: Виджет банковских операции

Модуль processing.py содержит функции для базовой обработки списков банковских транзакций

## Описание функции

в модуле processing.py реализованы две основные функции:

1.**filter_by_state** - фильтрует список банковских операции по их статусу
Результат:Новый список,содержащий только операции с указанным статусом.

2.**sort_by_date** - Сортирует список банковских операции по дате. 

## Как запустить тесты в PyCharm
Вы можете првоерить работу функции прямо из файла `src/processing.py`
